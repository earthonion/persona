Persona

Generate a random identity — name, username, disposable email, strong password — and autofill signup forms with one click.

Install for Firefox

Version 0.1.0 · Signed by Mozilla

This extension is for Firefox. Open this page in Firefox to install.

What it does

  • Generates a random first/last name, username, disposable email address, and strong password.
  • Fills signup forms on the active tab — including confirm-password fields.
  • All generation is local. No network. No telemetry. No tracking.

Usage

  • Click the Persona icon in your toolbar to open the popup.
  • Click ↻ to generate a new identity.
  • Click Fill current page to populate the active signup form.
  • Click Copy all to copy every field to your clipboard.

Privacy

Persona never transmits any data. Wordlists are bundled in the extension; generation uses the Web Crypto API locally. See the full privacy policy.
